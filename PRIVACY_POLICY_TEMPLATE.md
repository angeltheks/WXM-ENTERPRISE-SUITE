# Politica de privacidad - WXM ONE RADIO

Ultima actualizacion: [FECHA]

WXM ONE RADIO respeta tu privacidad. Esta app permite escuchar una emisora de radio online y consultar informacion basica de canciones reproducidas.

## Datos que podemos tratar

- Datos tecnicos necesarios para entregar el stream de audio.
- Solicitudes de metadata musical y caratulas.
- Datos anonimos o agregados de uso si se configura una herramienta de analitica en el futuro.

## Datos que no solicitamos

La app no solicita crear cuenta, no pide contrasenas, no solicita ubicacion precisa y no accede a contactos, camara, microfono ni archivos personales.

## Servicios de terceros

La app puede conectarse a:

- Servidor de streaming de WXM ONE RADIO.
- Spotify API, a traves de un proxy propio, para buscar caratulas.
- Apple iTunes Search API para caratulas alternativas.

Estos servicios pueden procesar datos tecnicos como direccion IP, agente de usuario y hora de la solicitud.

## Seguridad

Las credenciales de Spotify se mantienen en servidor y no se incluyen dentro de la app. Las comunicaciones se realizan por HTTPS cuando el servicio externo lo permite.
