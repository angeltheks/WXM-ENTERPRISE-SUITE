    Manual operativo / FAQ
    
                                
    Guia rapida para saber que es cada configuracion, para que sirve, que resultado da y como configurarla sin romper produccion.
    
                            
    
                            
    
                                
    
                                    Stream principal HTTPS
                                    
    Que es: la URL oficial de audio en vivo que reproduce la app.
    
                                    
    Resultado: al publicar el CMS, la app usa esa senal como fuente principal.
    
                                    
      
                                        
    1. Pega una URL `https://` de Icecast, Shoutcast, HLS o endpoint compatible.
      2. 
                                        
    2. Guarda borrador y revisa Validacion.
      3. 
                                        
    3. Configura al menos un fallback antes de produccion.
      4. 
                                    
    
                                
    
                                
    
                                    API de metadata HTTPS
                                    
    Que es: endpoint que entrega cancion, artista, portada o datos de emision.
    
                                    
    Resultado: mejora historial, lockscreen, notificacion y tarjetas de la app.
    
                                    
      
                                        
    1. Usa solo HTTPS.
      2. 
                                        
    2. Evita secretos en la URL publica.
      3. 
                                        
    3. Comprueba que responde estable desde red movil.
      4. 
                                    
    
                                
    
                                
    
                                    Fallback streams
                                    
    Que es: lista de senales secundarias usadas si la fuente principal falla.
    
                                    
    Resultado: menos cortes cuando hay caida temporal del proveedor principal.
    
                                    
      
                                        
    1. Agrega URLs HTTPS ordenadas por prioridad.
      2. 
                                        
    2. No uses la misma URL repetida.
      3. 
                                        
    3. Prueba cada fallback antes de publicar.
      4. 
                                    
    
                                
    
                                
    
                                    Reconexion y reintentos
                                    
    Que es: politica basica de recuperacion cuando el stream se corta.
    
                                    
    Resultado: la app intenta volver sin dejar loops infinitos.
    
                                    
      
                                        
    1. Usa 5000 ms como punto seguro para radio 24/7.
      2. 
                                        
    2. Sube el valor si hay red inestable.
      3. 
                                        
    3. No configures reintentos excesivos porque consume bateria.
      4. 
                                    
    
                                
    
                                
    
                                    Analytics endpoints
                                    
    Que es: URLs del backend que recibe eventos anonimos y devuelve dashboard.
    
                                    
    Resultado: audiencia real por app, web, pais, player, referrer y errores.
    
                                    
      
                                        
    1. Activa `Backend remoto` solo cuando exista API HTTPS.
      2. 
                                        
    2. Configura ingesta y dashboard en el submenu Analytics.
      3. 
                                        
    3. No envies datos personales; usa agregados y IDs anonimos.
      4. 
                                    
    
                                
    
                                
    
                                    Google Maps API
                                    
    Que es: opcion visual para mapa de oyentes conectado al dashboard CMS.
    
                                    
    Resultado: el panel muestra paises y conexiones con mapa interactivo.
    
                                    
      
                                        
    1. Crea una Browser API Key restringida por dominio.
      2. 
                                        
    2. Pegala solo en este panel local.
      3. 
                                        
    3. La key no se exporta al JSON publico de la app.
      4. 
                                    
    
                                
    
                                
    
                                    Endpoint CMS futuro HTTPS
                                    
    Que es: URL donde quedara publicado `wxm-cms.json` en hosting.
    
                                    
    Resultado: la app podra leer cambios remotos sin recompilar APK.
    
                                    
      
                                        
    1. Sube `wxm-cms.json` a hosting HTTPS.
      2. 
                                        
    2. Pega la URL publica aqui para pruebas.
      3. 
                                        
    3. Usa cache y versionado cuando pase a produccion.
      4. 
                                    
    
                                
    
                                
    
                                    Endpoint upload assets
                                    
    Que es: API privada que recibe imagenes del CMS y devuelve URLs publicas.
    
                                    
    Resultado: las imagenes dejan de ir embebidas y cargan como assets optimizados.
    
                                    
      
                                        
    1. Levanta el `cms-remote-starter` o backend equivalente.
      2. 
                                        
    2. Configura autenticacion y `WXM_CMS_PUBLIC_BASE_URL`.
      3. 
                                        
    3. Sube imagenes locales y publica el contrato resultante.
      4. 
                                    
    
                                
    
                                
    
                                    Modo emergencia
                                    
    Que es: interruptor editorial para incidencias, mantenimiento o stream alterno.
    
                                    
    Resultado: la app puede mostrar aviso y usar senal temporal segura.
    
                                    
      
                                        
    1. Activalo solo si hay incidencia real.
      2. 
                                        
    2. Escribe un mensaje breve y claro.
      3. 
                                        
    3. Si cambias stream, usa HTTPS y prueba antes.
      4. 
                                    
    
                                
    
                                
    
                                    Visual y audio
                                    
    Que es: tema, color, hero y perfil recomendado para la experiencia de usuario.
    
                                    
    Resultado: la app adapta portada, apariencia y sugerencia de audio desde CMS.
    
                                    
      
                                        
    1. Usa imagen hero 1920x1080 o 1600x900.
      2. 
                                        
    2. Define un color hexadecimal valido.
      3. 
                                        
    3. El perfil de audio debe coincidir con opciones de la app: standard, club, voice, night, wide.
      4.
